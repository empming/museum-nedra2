# Горная летопись России · 1991–2022

Виртуальный музей развития российской горнодобывающей отрасли с 1991 по 2022 год. Проект по курсу «История России» (НИУ ВШЭ).

**Live:** https://empming.github.io/museum-nedra2/

## Структура

Одностраничник на чистом HTML/CSS/JS + Leaflet (карта) + Chart.js (графики).

Разделы:
1. **Hero** — обложка с ключевыми цифрами.
2. **Пролог** — почему сквозной герой музея — ПАО «Селигдар».
3. **Хронолента 1991–2022** — горизонтальный скролл, 22 события со ссылками на первоисточники.
4. **Карта** — 14 месторождений на Leaflet/OpenStreetMap.
5. **Цифры эпохи** — графики LBMA Gold Price, добыча РФ, добыча Селигдара.
6. **Четыре зала** — приватизация, IPO, регионы, экология/КСО.
7. **Финансовый эпилог** — золотая облигация Селигдара (GOLD01) с интерактивным калькулятором.
8. **Артбук** — галерея из 16 изображений корпоративного издания «Селигдар. 40 лет».
9. **Источники** — ссылки на годовые отчёты компаний, законы, статистику.

## Источники

Первичный визуальный источник — корпоративный артбук «Селигдар. 40 лет. Золотая поступь Селигдара» (2015, 83 страницы, 247 фотографий). Изображения извлечены и отрендерены скриптами `scripts/extract_artbook.py` и `scripts/render_pages.py`.

Все факты в карточках хронолинии, на карте и в залах имеют ссылку на первоисточник (закон, годовой отчёт, материал из публичной базы pravo.gov.ru/cbr.ru/LBMA).

## Локальный запуск

```
python -m http.server 8080
```

Открыть http://localhost:8080/.

## Стек

- Pure HTML/CSS/JS (ES modules, без сборщика).
- [Leaflet 1.9.4](https://leafletjs.com/) + OpenStreetMap.
- [Chart.js 4.4.1](https://www.chartjs.org/).
- Шрифты: Cormorant Garamond + Manrope (Google Fonts).
- Деплой: GitHub Pages из ветки `main`.
